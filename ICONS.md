# Orthodox icons, pictograms, and illustrations

Canonical religious marks for this parish template. Utility UI icons (Lucide) are separate and must not carry Western Catholic/Protestant meanings.

**Hard rules:** no Latin crosses where an Orthodox cross is meant; no rosary, monstrance, Sacred Heart, Latin chalice-and-host, praying hands, or dove-only clip art; no Western steeples — onion domes on drums with crosses; Slavic three-bar footrest always higher on the viewer’s **left** (never RTL-mirrored).

## Crosses (`src/lib/cross.ts` → `Cross.astro`)

| Variant | Meaning |
| --- | --- |
| `byzantine` | Equal-armed Greek/Byzantine cross with flared arms and bead finials (default site mark). |
| `icxc` | Same cross with **IC XC / NI KA** in the quadrants (Christ conquers). |
| `slavic` | Eight-pointed Russian cross: short titulus, long crossbar, footrest slanting **up-left / down-right**. |

Favicon (`public/favicon.svg`): Byzantine cross in a temple silhouette — appropriate for a Greek parish; not a Latin cross.

## Pictograms (`src/components/Pictogram.astro`)

| Name | Meaning |
| --- | --- |
| `cross` | Delegates to the Byzantine cross component. |
| `church` | Nave with **onion dome on a drum** and cross; not a steeple. |
| `chalice` | Communion cup marked with an Orthodox cross. |
| `censer` | Thurible suspended on chains, with lid and foot. |
| `candle` | Lit beeswax taper in a stand. |
| `prayer-rope` | Komboskini / chotki with knotted cross and tassel. |
| `gospel` | Closed Gospel book with cover cross and bosses. |
| `icon-frame` | Arched icon panel (kiot) with a small cross. |
| `bells` | Belfry under an onion cupola (not a Western steeple). |
